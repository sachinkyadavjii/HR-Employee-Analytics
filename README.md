# HR Employee Analytics & Attrition Prediction

An end-to-end HR analytics project: it cleans and explores a synthetic
employee dataset, analyzes it with SQL, calculates HR KPIs, visualizes
attrition patterns in an interactive Streamlit dashboard, and predicts
attrition risk with a machine learning model.

Built as a portfolio project for **Python Developer** and **Data
Analyst / HR Analyst** roles.

## Project Overview

Employee attrition (staff leaving a company) is one of the most expensive
and disruptive problems an HR team deals with. This project simulates a
realistic HR analytics workflow: understand who is leaving, why they might
be leaving, and which employees are currently at higher risk - using the
kind of stack (Python, SQL, ML, dashboards) an HR analyst or data analyst
would actually use.

## Business Problem

> "Which employees are at risk of leaving, what factors are driving
> attrition across the company, and what can HR do about it?"

This project answers that question using a full analytics pipeline:

```
Raw HR Data → Data Cleaning → EDA → SQL Analysis → KPI Calculation
           → Interactive Dashboard → Attrition Prediction → Business Insights
```

## Objectives

- Clean and validate a realistic HR employee dataset
- Explore attrition patterns across department, role, tenure, pay, and more
- Answer HR analyst questions with SQL
- Calculate and surface company-wide HR KPIs
- Build an interactive dashboard for non-technical stakeholders
- Predict individual employee attrition risk with a classification model
- Turn the analysis into concrete, evidence-based HR recommendations

## Features

- **1,200-record synthetic HR dataset** with realistic (not perfect) links
  between attrition and known risk factors
- **Automated data cleaning pipeline** with a printed data-quality summary
- **Jupyter notebook EDA** covering 12 different attrition breakdowns plus
  a Job Role x Department attrition heatmap
- **SQLite database + 15 SQL queries** answering common HR analyst
  questions
- **Logistic Regression vs Random Forest** comparison, evaluated on
  accuracy, precision, recall, F1, and ROC-AUC - honestly reported, not
  inflated
- **Interactive Streamlit dashboard** with filters, KPI cards, charts, a
  live prediction tool, and an in-app SQL insights page
- **Auto-generated business insights report** with finding / evidence /
  explanation / recommendation for each insight

## Dataset

The dataset (`data/hr_employee_data.csv`) is **synthetic** - generated by
`src/data_generator.py` - and contains 1,200 employee records with 29
fields including demographics, compensation, satisfaction scores, tenure,
performance, and attrition status. Attrition is deliberately linked (with
realistic noise, not a perfect rule) to factors like overtime, low job
satisfaction, low work-life balance, lower pay, short tenure, long commutes,
lack of promotion, and frequent travel, so the downstream analysis has real
patterns to uncover.

Regenerate it any time with:

```bash
python src/data_generator.py
```

## Data Cleaning

`src/data_cleaning.py` loads the raw CSV and:

- Checks shape, dtypes, missing values, and duplicates
- Removes duplicate rows
- Fills missing numeric values with the median and categorical values with
  the mode
- Validates numeric ranges (age, income, etc.) and the `Attrition` column
- Prints a data-quality summary
- Saves `data/hr_employee_data_clean.csv`

```bash
python src/data_cleaning.py
```

## Exploratory Data Analysis

`notebooks/HR_Employee_Analysis.ipynb` covers:

- Dataset overview and data-quality checks
- Company-wide HR KPIs
- Attrition by department, job role, gender, age group, salary range,
  years at company, overtime, job satisfaction, work-life balance,
  promotion history, business travel, and job level
- A Job Role x Department attrition heatmap
- Correlation of numeric features with attrition

## SQL Analysis

`src/database.py` loads the cleaned data into a local SQLite database
(`data/hr_database.db`). `sql/hr_queries.sql` contains 15 commented queries
covering department/role breakdowns, salary comparisons, overtime and
satisfaction counts, promotion history, and rule-based "at risk" employee
segments.

```bash
python src/database.py
sqlite3 data/hr_database.db < sql/hr_queries.sql
```

## Machine Learning

`src/prediction.py` trains and compares a **Logistic Regression** and a
**Random Forest** classifier to predict attrition:

- Categorical features are one-hot encoded, numeric features are scaled
- The model is selected by **ROC-AUC** on a held-out test set (a good
  metric for the class imbalance typical of attrition data)
- Metrics (accuracy, precision, recall, F1, ROC-AUC, confusion matrix) are
  printed honestly - this is a portfolio-scale demonstration, not a
  claim of production-grade accuracy
- **Gender and marital status are excluded from the model's input
  features**, since using protected attributes as direct predictive inputs
  could contribute to unfair employment decisions
- The trained pipeline (preprocessing + model) is saved with Joblib to
  `models/attrition_model.pkl`

```bash
python src/prediction.py
```

## Dashboard

`dashboard/app.py` is a Streamlit app with:

- **Overview** - top-level KPIs and workforce/attrition summary charts
- **Employee Analysis** - workforce demographics and composition
- **Attrition Analysis** - attrition broken down by every major factor,
  plus the Job Role x Department heatmap
- **Prediction** - enter an employee profile and get an attrition
  probability, risk level, and the model's most influential factors
- **SQL Insights** - key HR metrics queried live from SQLite, with the SQL
  shown underneath each result
- **About** - project purpose, tech stack, and limitations

All KPIs and charts are calculated dynamically from the (optionally
filtered) dataset - nothing is hardcoded.

## Key Insights

See [`reports/business_insights.md`](reports/business_insights.md) for the
full write-up. Headline findings from the current dataset:

- Employees working overtime leave at **more than double** the rate of
  those who don't (32.0% vs 13.6%)
- Employees in their first two years have a **36.7%** attrition rate,
  versus **10.4%** for employees with over 10 years of tenure
- Employees who left earned **~23% less**, on average, than employees who
  stayed
- Attrition falls steadily as job satisfaction rises (32.6% at the lowest
  satisfaction level down to 13.7% at the highest)
- Employees without a promotion in the last 5 years leave at a
  meaningfully higher rate (23.5% vs 16.1%)

## Disclaimer

The dataset used in this project is **entirely synthetic** and was
generated for demonstration purposes - it does not represent any real
company or real employees. The attrition prediction model is an
**educational/portfolio demonstration** of a classification workflow, not a
production HR decision-making system, and should never be used as the sole
basis for real employment decisions.
